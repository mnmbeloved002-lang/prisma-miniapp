# Sources Inventory — Phase 2 / Step 1.1

> Базовый список источников для авто-парсинга. Детализацию (конкретные URL/эндпоинты) дополним без изменения структуры.

| id           | роль            | тип       | базовый домен/канал | формат   | примечания |
|--------------|-----------------|-----------|----------------------|----------|-----------|
| primary      | основной сайт   | site      | <указать>            | HTML/RSS | главный источник новостей |
| secondary    | резервный сайт  | site      | <указать>            | HTML/RSS | используется при деградации primary |
| aggregator   | fallback        | rss       | <указать>            | RSS      | агрегатор как запасной канал |

## Политики по источникам (общие)
- **robots.txt** и пользовательский `User-Agent`: MiniAppBot/1.0
- **rate limit per host**: ≤ 0.2 rps (1 запрос / 5 сек), concurrency = 1
- **таймауты**: connect 5s • response 10s • hard 20s
- **ретраи**: 3 попытки, backoff 2s → 5s → 13s
- **окна тишины**: уважать ночные окна источника (если документированы)
- **«0 новостей»**: не ошибка, но помечается WARN в Compliance

## Сигналы деградации (для Predictive Alerts)
- рост 4xx/5xx на источнике
- рост TTFPR
- падение среднего количества новых материалов за окно
