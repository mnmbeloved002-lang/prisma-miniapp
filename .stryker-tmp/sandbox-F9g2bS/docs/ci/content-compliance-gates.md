# Content Compliance - Блокирующие гейты

## Критические проверки:
- Соответствие контракту данных
- Формат ветки: bot/autofetch-*
- Allow-list файлов
- Лимит размера diff: ≤100KB
- Запрет параллельных контент-PR
- Политика "0 новостей"

## Статусы:
- 🔴 Красный: блокирующие ошибки
- 🟡 Желтый: предупреждения  
- 🟢 Зеленый: успех
