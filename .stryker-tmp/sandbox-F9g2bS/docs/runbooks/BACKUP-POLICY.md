# Политика бэкапов news.json

## Цель
Быстрое восстановление данных при потере или повреждении.

## Правила
- Бэкап создается при каждом изменении news.json
- Хранятся в archive/backups/
- Восстановление ≤ 5 минут

## Восстановление
```bash
# Найти последний бэкап
cp archive/backups/news.json.backup.latest public/news.json
