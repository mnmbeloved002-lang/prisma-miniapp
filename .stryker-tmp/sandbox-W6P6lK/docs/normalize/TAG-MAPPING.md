# Tag Mapping — Phase 2 / Step 1.2

## Наш словарь (минимальный старт)
- экономика, технологии, политика, спорт, культура, общество, мир, бизнес

## Примеры маппинга
- "Экономика" / "Финансы" → **экономика**
- "Технологии" / "ИТ" / "Digital" → **технологии**
- "Политика" → **политика**
- "Спорт" → **спорт**
- "Культура" / "Шоу-бизнес" → **культура**
- "Общество" → **общество**
- "Мир" / "В мире" → **мир**
- "Бизнес" → **бизнес**

Примечания: регистр → lowerCase, пробелы сжать; пустые/мусорные — отбрасывать; итог 1..5 тегов.
