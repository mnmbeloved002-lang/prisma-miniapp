# Метрики и алерты контент-пайплайна

## Ключевые метрики:
- TTFPR: время от парсинга до PR
- Новых новостей: количество за прогон
- Ошибки парсинга: по источникам
- Пустые прогоны: количество подряд
- Длительность ревью: среднее время

## Пороги алертов:
- TTFPR > 15 мин → критический
- Ошибки > 50% → критический
- Пустые прогоны > 3 → предупреждение
