# Регламент локальной валидации news.json

## Процесс валидации
1. Запустить: `node scripts/validate-news.cjs`
2. Проверить что нет ошибок (только ✅ в выводе)

## Эталонные сообщения об ошибках
❌ Запись {index}: отсутствует обязательное поле "{field}"
❌ Запись {index}: дубликат id "{id}"  
❌ Запись {index}: дубликат url "{url}"
❌ Запись {index}: дубликат комбинации title+date
❌ Запись {index}: дата должна заканчиваться на Z (UTC) - "{date}"
❌ Запись {index}: URL должен начинаться с https:// - "{url}"
❌ Запись {index}: title должен быть 10-180 символов - {length}
❌ Запись {index}: тег "{tag}" должен быть 2-24 символа
❌ Нарушена сортировка: запись {prev} ({prev_date}) должна быть после {curr} ({curr_date})

## Чек-лист перед коммитом
- [ ] Запущен `node scripts/validate-news.cjs`
- [ ] Нет критических ошибок
- [ ] Все проверки пройдены ✅
