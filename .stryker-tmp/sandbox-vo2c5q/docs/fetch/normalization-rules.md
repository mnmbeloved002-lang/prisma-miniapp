# Правила нормализации и маппинга

## Процесс преобразования:
1. Парсинг → сырые данные
2. Очистка → удаление HTML, нормализация
3. Валидация → проверка полей
4. Трансформация → целевой формат
5. Обогащение → ID, теги, превью

## Правила для полей:

### ID
- Генерация стабильного UUID на основе title+date+url

### Title  
- Удаление HTML тегов
- Нормализация пробелов
- 10-180 символов

### Preview
- Удаление HTML
- ≤240 символов
- Если пусто - создать из content

### Tags
- Из категорий RSS + автоматическая классификация
- 1-5 тегов, каждый 2-24 символа
- Резерв: ["новости"]

### Date
- Любой формат → ISO 8601 UTC с Z

### URL
- Только HTTPS
- Удаление UTM-меток
