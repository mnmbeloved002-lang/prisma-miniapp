# ИЕРАРХИЯ ПРИОРИТЕТОВ — PRISMA RITUAL AI ECOSYSTEM
Источник правды по порядку важности (ERL-31 MUST)

1. Безопасность (AppSec, XSS, CSP, initData validation)
2. Целостность данных (Integrity Chain, DQM, Zod)
3. Надёжность (SLO 99.99%, runbook ≤5 мин, self-healing)
4. Качество кода (тесты, mutation score ≥85%, zero-debt)
5. Производительность (Lighthouse ≥95, size-limit ≤650 КБ)
6. Скорость разработки (только после 1–5)

Любое решение, нарушающее 1–4 ради 5–6, запрещено.
