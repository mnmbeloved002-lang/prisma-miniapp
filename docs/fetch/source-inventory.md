# Инвентарь источников и политика парсинга

## Выбранные источники (2-3 для начала)

### 1. RSS Источник: Lenta.ru
- **URL**: https://lenta.ru/rss/news
- **Тип**: RSS
- **Частота**: каждые 30 минут
- **SLA**: 95% успешных запросов
- **Ретраи**: 3 попытки с экспоненциальной задержкой
- **Таймаут**: 10 секунд
- **robots.txt**: соблюдать

### 2. RSS Источник: РИА Новости
- **URL**: https://ria.ru/export/rss2/index.xml
- **Тип**: RSS  
- **Частота**: каждые 45 минут
- **SLA**: 90% успешных запросов
- **Ретраи**: 2 попытки
- **Таймаут**: 15 секунд
- **robots.txt**: соблюдать

### 3. Fallback: Meduza (RSS)
- **URL**: https://meduza.io/rss2/all
- **Тип**: RSS
- **Частота**: только при недоступности основных
- **SLA**: резервный канал

| РИА Новости | `*/45 * * * *` | 5 минут |
| Fallback | `0 */6 * * *` | - |

## Политика обхода

### Троттлинг
- Между запросами к одному домену: 2 секунды
- Между разными источниками: 30 секунд

### Обработка ошибок
- **Таймаут запроса**: 30 секунд
- **Максимум ретраев**: 3
- **Задержка между ретраями**: 1, 5, 15 секунд
- **Коды ошибок для ретрая**: 429, 500, 502, 503

### Политика "0 новостей"
- Если за 24 часа не найдено ни одной новости → алерт
- Если все источники недоступны → fallback на кэшированные данные
- Пустой результат ≠ ошибка (возможно просто нет новостей)

### robots.txt
- Соблюдать Crawl-delay
- Уважать Disallow
- User-Agent: PrismaNewsBot/1.0 (+https://github.com/mnmbeloved002-lang/prisma-miniapp)

## Fallback-стратегия

1. **Основные источники**: Lenta.ru + РИА Новости
2. **Резервные**: Meduza
3. **Аварийный режим**: локальный кэш последних успешных данных
4. **Полный отказ**: возврат пустого массива с записью в лог

## Мониторинг

- **Метрики доступности**: успешные/неуспешные запросы
- **Латентность**: время ответа каждого источника
- **Объем данных**: количество новых новостей за прогон
- **Алерты**: при >50% ошибок за час
