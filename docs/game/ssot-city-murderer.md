# SSOT: Городской убийца (Rules-as-Code Source)

Этот документ — нормативный источник для движка и тестов.
Формат: MUST/SHALL, RuleID, инварианты, без “прозы”.

## SSOT-000 Сущности и инварианты

- Поле: 4×4 квартала, максимум 3 жителя в квартале.
- Соседство: по стороне (N/E/S/W), без диагоналей (кроме зон “вокруг детектива” для мотива Вигилант).
- Житель: profession (уникальна), socialGroup, gender, age, body, height, intimidated.
- Житель intimidated = true считается “запуганным”, его нельзя допрашивать (но его можно убивать, если мотив не запрещает).
- Детектив стоит в одном квартале; убийца не может:
  - запугивать жителей в квартале детектива
  - убивать жителя в квартале детектива
- “Место преступления” кладётся в квартал жертвы; жертва уходит в зону жертв. Всего мест преступления/жертв: 5.

## SSOT-010 Подготовка (Логика)

- В режиме “Логика” отсутствуют: карты детектива, карты убийцы, жетоны улик.
- Раскладка жителей: по 2 жителя в углы, по 1 — в остальные кварталы; все спокойной стороной.
- Мотивы: выбирается набор мотивов, убийца выбирает 1 мотив (секретно).

## SSOT-020 Раунд

Раунд: Фаза убийцы → Фаза детектива → Фаза города.

## SSOT-030 Фаза убийцы

- Запугивание: убийца запугивает 2 жителей (переворот intimidated=true).
  - запрещено запугивать в квартале детектива
  - можно запугать самого себя
- Убийство:
  - жертва соответствует мотиву
  - жертва не в квартале детектива
  - жертва не является убийцей

## SSOT-040 Фаза детектива (минимум для движка)

- Срочный вызов: детектив перемещается в квартал нового места преступления.
- Расследование: 2 разных действия + 2 очка движения (движение до/между/после действий).

## SSOT-050 Слежка (минимум для движка)

- Вопрос слежки: “Может ли убийца убить этого жителя прямо сейчас?”
- Если жетон слежки поставлен на убийцу или детектив в одном квартале с целью слежки: ответ “Нет”.

## SSOT-060 Фаза города (минимум для движка)

- Перемещение жителей по вытянутой соцгруппе: каждый житель этой соцгруппы делает 1 шаг в соседний квартал.
- Жителям запрещено входить в кварталы с местом преступления.
- Жителям запрещено входить в квартал с 3 жителями.
- Если невозможно переместить по соседству (все соседи запрещены) — допускается переместить “в любые кварталы” (без adjacency).

## SSOT-100 Мотивы как ограничения убийства (Rules-as-Code)

Для функции canKillNow(state, victim):

- MANIAC: все жертвы одного пола.
- SADIST: нельзя убивать intimidated=true.
- VIGILANTE: нельзя убивать в “3×3 вокруг детектива” (Chebyshev distance ≤ 1), кроме самого квартала детектива (он запрещён базовым правилом).
- HITMAN: можно убивать только в квартале, где ровно 1 житель.
- THUG: нельзя убивать в 4 центральных кварталах.
- TERRORIST: все жертвы из разных соцгрупп.
- ROBBER: нельзя убивать в квартале, соседнем по стороне с предыдущим местом преступления.
- RADICAL: по итогам игры минимум 3 жертвы одной соцгруппы (движок обязан отсекать ходы, которые делают это невозможным).
- PSYCHOPATH: все жертвы максимум двух возрастов.
- CANNIBAL: среди жертв должны быть все 3 телосложения (движок обязан отсекать ходы, которые делают это невозможным).
- SPY / CULTIST: требуют suspectId (фигурант), вводятся как расширение (сейчас — минимальная поддержка feasibility/форс-условий).
